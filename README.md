📺🌍 Televisión por Internet para todos

🚀 IPTV Libre es un proyecto gratuito y de código abierto para disfrutar de televisión por Internet mediante listas IPTV públicas y legales. Su objetivo es ofrecer una experiencia sencilla, moderna y accesible desde dispositivos compatibles.

🌐 Página web oficial: https://tdtsp.github.io/

📱🎮 Plataformas compatibles
🎮 PlayStation 4 (PS4): acceso mediante el navegador de la consola, siempre que sea compatible con el reproductor web.
📱 Android: aplicación instalable mediante APK.
📺 Android TV: versión adaptada a televisores y dispositivos Android TV compatibles.

🌐 Versión web: tdtsp.github.io

ℹ️ La compatibilidad depende del dispositivo, el navegador, el reproductor y las fuentes IPTV utilizadas. PS4 no permite instalar directamente archivos APK de Android.
✨ Características principales
🆓 Gratuito y sin suscripciones de pago a la aplicación.
📡 Compatible con listas IPTV públicas en formatos M3U y M3U8, según las funciones implementadas.
🌍 Acceso a fuentes de canales de diferentes países.
🚫 Sin publicidad integrada en el reproductor, como objetivo del proyecto.
🎨 Interfaz moderna, intuitiva y con modo oscuro.
🔒 Código abierto, con atención a la privacidad y la seguridad.
📱 Experiencia adaptada a dispositivos compatibles.
🤝 Comunidad abierta a mejoras, sugerencias y correcciones.
🚀 Cómo acceder
🎮 PlayStation 4
Abre el navegador de Internet de tu PS4, si está disponible.
Visita https://tdtsp.github.io/.
Comprueba si el reproductor web funciona correctamente en tu consola.
📱 Android
Visita https://tdtsp.github.io/.
Accede al enlace de descarga del APK cuando esté disponible.
Instala la aplicación si el archivo publicado es compatible con tu dispositivo.
📺 Android TV
Accede a https://tdtsp.github.io/ desde un dispositivo compatible.
Descarga la versión de Android TV cuando esté disponible.
Instala y utiliza la aplicación siguiendo las instrucciones correspondientes.
🛠️ Tecnologías
🐍 Python, cuando corresponda a los componentes de la aplicación.
📺 Tecnologías web para la versión accesible desde navegador.
🎬 Motor multimedia compatible con las plataformas de destino.
🚧 Estado del proyecto

IPTV Libre es un proyecto comunitario en desarrollo.

La disponibilidad de las versiones para Android y Android TV depende de su compilación, sus pruebas y su publicación. El acceso desde PS4 depende de la compatibilidad del navegador de la consola con la versión web.

⚖️ Uso responsable

IPTV Libre está destinado al uso de listas IPTV públicas y fuentes autorizadas.

No se distribuyen listas privadas ni suscripciones de pago filtradas.
No se promueve el acceso a retransmisiones sin autorización.
La disponibilidad y legalidad de los canales dependen de sus respectivas fuentes y de los derechos aplicables.

El usuario es responsable de utilizar fuentes de contenido legítimas.
