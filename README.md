📺🌍 IPTV Libre — Televisión gratis para todos

🚀 IPTV Libre es un proyecto gratuito y de código abierto para disfrutar de televisión por Internet mediante listas IPTV públicas y legales, sin publicidad integrada en la aplicación y con una interfaz moderna, sencilla y fácil de utilizar.

💻 Formatos disponibles según el dispositivo:

🪟 Windows: aplicación ejecutable .exe.
🐧 Linux: aplicación .AppImage.
🤖 Android: aplicación instalable .apk.

✨ Características principales:

🆓 Totalmente gratuito, sin suscripciones de pago a la aplicación.
📡 Compatible con listas IPTV públicas en formatos M3U y M3U8.
🌍 Fuentes de canales de diferentes países.
🚫 Sin anuncios integrados en el reproductor.
🎨 Interfaz moderna, intuitiva y con modo oscuro.
🔒 Código abierto, con especial atención a la privacidad y la seguridad.
🤝 Comunidad abierta para aportar mejoras y fuentes legales.
📱 Una experiencia adaptada a cada dispositivo compatible.

❤️ ¡Tu colaboración es bienvenida! Puedes aportar código, informar de errores, proponer nuevas funciones o compartir listas IPTV públicas y autorizadas.

⚠️ No se distribuyen listas privadas, suscripciones de pago filtradas ni retransmisiones deportivas sin autorización. La disponibilidad de los canales depende de sus respectivas fuentes.

🛠️ Tecnologías: Python, CustomTkinter y un motor multimedia compatible.

🚧 Proyecto comunitario en desarrollo. Los formatos .exe, .AppImage y .apk estarán disponibles cuando se compilen, prueben y publiquen sus respectivas versiones.

🌟 IPTV Libre: software libre, televisión por Internet y tecnología para todos. 📺🐍🌍
